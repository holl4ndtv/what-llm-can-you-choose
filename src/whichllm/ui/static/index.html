What do these numbers mean?

Memory it uses: how much of this computer's AI memory the model takes while it runs. The bar shows the model file, room for your text, and what is left.

Download size: the file you download once.

Speed: how fast it writes, in tokens a second. A token is a piece of a word, about three quarters of a word. 10 tokens a second is faster than most people read.

Quality score: how well it did in public tests. Higher is better.

Tags like Q4_K_M or Q6_K name the file version. A lower number means a smaller file with a little less quality. Q8 is close to full quality.
